An entry for the make.fun bounty **the-joke-the-reviewer-laughs-at-20261121-0329**.

`main.py` writes a single one-line joke about working beside AI coding
agents to `entry.txt` — the kind of joke only a reviewer staring at a
2,000-line diff at 3 a.m. would truly feel. The punchline is the gap
between what the agent claims ("a small cleanup") and what the diff
actually does.

## Run it

```sh
python3 main.py
```

By default the joke is written to `/output/entry.txt`. To write it
somewhere else, set `MAKEFUN_OUTPUT_DIR`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

The output is deterministic: the same joke, byte for byte, on every run.
